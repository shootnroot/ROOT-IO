ROOT /IO Demo Mode

Upload index.html, demo-config.js, and sw.js to the root of your GitHub Pages repository. Replace index.html and sw.js.

DEMO MODE ON (default): demo-config.js -> window.ROOTIO_DEMO_MODE = true;
DEMO MODE OFF: change true to false, commit, and refresh/reopen the app.

The Setup & sources button is hidden and navigation to its screen is blocked in demo mode. This is only a client-side UI control, NOT security or access control. Do not publish private machine data or credentials.

Existing social image rootio-social-v3.png should remain in your repository.
